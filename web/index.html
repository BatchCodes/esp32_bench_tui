ESP32 Bench TUI

Bench Agent Web Flasher

Flash the bench agent firmware to an ESP32 board from this page. You do not need to install ESP-IDF or Python. After the flash, the bench TUI on your computer sends the pin configuration to the board.

This browser does not support Web Serial. Open this page in Chrome, Edge or Opera on a desktop computer.

Web Serial needs a secure page. Open this page over HTTPS or from localhost.

Firmware version unknown

Steps

  1. Connect the board to this computer with a USB data cable.
  2. Click Connect and install, then select the serial port of the board.
  3. If the page cannot connect, hold the BOOT button of the board. Click Connect and install again, and release BOOT when the flash starts.
  4. When the flash is done, close the install window. The window keeps the serial port open until you close it.
  5. Start the bench TUI on your computer: ./bench.

The flash replaces the firmware that is on the board. To keep a copy of it, make a backup first: python3 -m esptool --port /dev/ttyUSB0 read_flash 0 ALL backup.bin

Supported Chips

The page reads the chip type from the board and selects the correct firmware.

Chip USB port of the board Serial link of the bench agent
ESP32 USB-to-UART bridge UART0
ESP32-S3, ESP32-C3, ESP32-C6 USB-to-UART bridge UART0
native USB of the chip USB-Serial-JTAG

Use the same USB port for the bench TUI that you use for the flash.
