Bench TUI

Connect to a board that runs the bench agent, then read its pins and control its outputs. The page runs the bench TUI in your browser. You do not need to install anything. To install the bench agent on a board, use the web flasher.

This browser does not support Web Serial. Open this page in Chrome, Edge or Opera on a desktop computer. To try the TUI with no board, open the simulator.

How to Use It

  1. Connect the board to this computer with a USB data cable.
  2. Choose a project, or open mode.
  3. Click Connect board and start, then select the serial port of the board.
  4. Use the TUI keys, the same as in the terminal. ctrl+s downloads the project file.
  5. q stops the TUI and frees the serial port.
