Bench TUI Simulator

Try the bench TUI with a simulated ESP32 board. The simulated bench agent answers the same as a real board: the inputs change, and the outputs follow the keys that you press. It works in every browser, and you need no hardware.

This is a demo. No board is connected. To install the bench agent on a board, use the web flasher. To connect to a board, open the TUI page.

Things to Try

  • Choose the example "A potentiometer, a servo and a PWM output". Press p for the Pins page.
  • Move to an output with ↑ and ↓, and press enter to change it.
  • Press space on an input to see its chart.
  • Press w and t for the simulated Wi-Fi and Bluetooth scans.
  • ctrl+s downloads the project file. q stops the TUI.
